# 目覚まし性癖占い

日ごとの性癖ランキング占いサイトです。

## 入れた機能

- オンライン日付APIを使った毎日ランキング
- 上位15個と下位15個の表示
- 全部のランキング表示ボタン
- ランキング項目ごとの通報ボタン
- 複数通報された性癖をランキングから削除
- ランキングクリックで詳細表示
- `app.js` 内に 74〜25 までの性癖偏差値表を全段収録
- 性癖追加はリクエスト制。同じ性癖名が2回リクエストされたら正式追加
- 性癖追加リクエスト時に、関連ラッキーアイテム名と説明を2〜4個登録
- 同じ性癖名は正式追加時に自動で統合
- ラッキーアイテムごとの画像表示
- 画像がないラッキーアイテムは「画像なし」表示
- ラッキーアイテム画像アップロード
- 高評価/低評価
- 低評価が5回になると、アップロード画像と関連する追加性癖を削除
- 詳細コメントは30セット、それぞれ3パターンから日替わりで表示

貼り付け素材には公開サイト向けではない語が含まれていたため、偏差値表は安全寄りの表現に置き換えています。

## まず見る

`index.html` をブラウザで開くと見られます。

## 公開するなら

GitHub Pagesで公開できます。

1. GitHubで新しいリポジトリを作る
2. このフォルダの中身をリポジトリに入れる
3. GitHubの `Settings` → `Pages` を開く
4. `Deploy from a branch` を選ぶ
5. `main` ブランチの `/root` を公開元にする
6. 表示されたURLを開く

今の追加・評価・アップロードはブラウザ内保存です。全員で共有したい場合は、GitHub Pagesに加えて Supabase や Firebase の保存先が必要です。

公開サイトで投稿を受け付けるなら、禁止ワード、通報、管理者削除、レート制限を入れるのがおすすめです。
